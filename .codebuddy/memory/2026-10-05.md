## Whitelist `;cmd` 不触发修复 (src/games/universal - base/base.lua)
- 症状:白名单命令完全不触发(自己或别人发都没反应)。
- 根因:`whitelist:hook()` 只在 `playeradded` 里被调用,而 `playeradded` 仅在 `get(v) ~= 0`(检测到白名单玩家)时触发。若白名单加载失败或本地玩家没匹配进白名单,聊天 hook 永远不安装 → `process()` 永不调用 → 命令全无反应。
- 修复:
  1. `whitelist:update()` 中在 `pcall` 后立即无条件调用 `self:hook()`(受 `self.hooked` 守卫,幂等),保证命令可达。
  2. `whitelist:process()` 中本地玩家(`plr == lplr`)绕过 `getplayer` 名字过滤,直接以第一个 token 作为命令自身参数运行。远端白名单用户仍须通过 `getplayer` 名字/等级过滤。
- 备注:本仓库 base.lua 的 whitelist 逻辑与上游 7GrandDadPGN/VapeV4ForRoblox 逐字一致(仅 whitelist 仓库 URL 改为 Night5449791/whitelists,以及 Announcement 判空保护)。远端命令仍依赖白名单成功加载(`localprio < get(plr)`)。
