# 2026-10-02

## json.lua library
- Created `src/libraries/json.lua`: minimal JSON file I/O for Roblox executors.
  - API: `json.write(path, content)`, `json.read(path)` (also exposes `encode`/`decode`).
  - Encoder/decoder prefers executor globals `jsonEncode`/`jsonDecode`, falls back to `HttpService:JSONEncode/JSONDecode`.
  - File ops use executor globals `writefile`/`readfile`/`isfile`/`isfolder`/`makefolder`; `write` auto-creates the parent folder via `ensureFolder`.
  - `read` returns `nil` when the file is missing or decode fails.
